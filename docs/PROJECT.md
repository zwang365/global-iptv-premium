# 项目维护

目标频道白名单在 `data/whitelist.json`；海外63项是用户指定的完整目标，不代表63项可播放。PBS已删除，ABC为澳洲ABC，FOX按Fox News处理，BBC World Service按广播标记。

`data/source-policy.json`逐频道限制经过审阅的官方网站/CDN前缀；候选仓库本身不构成授权证明。新增域名必须核实频道身份与公开分发依据，不能通过扩宽前缀引入无关频道。尊重iptv-org移除清单。BBC频道、同名地方版本、FAST替代频道不可混用。

主订阅只写入大陆直连下HLS清单、分片、视频解码、直播序列推进均通过的720/1080视频。常规公开AES-128可支持；DRM、登录、特殊令牌、付费认证、错台和占位片不收录。4K暂未纳入本版兼容性范围。探测是短时采样，不证明全天稳定或用户电视一定支持。

源目录失效、非大陆出口、没有解码器或全部候选失败时，保留上次有效订阅；失败通过工作流状态提示。不要把旧订阅误称为新一轮验证结果。初始本地检测可用6小时以内的同网络缓存复现；Actions每次重新实测。出于可审计性，单条check时间戳才是实际播放检测时间，报告生成时间不代替它。

运行测试：`python3 -m unittest discover -s tests -v`。

生产仓库根目录存放`.github/workflows/`，程序在`global-iptv-premium/`子目录。不要把工作流放在该子目录中；GitHub不会在那里识别工作流。日常新增、删减或重新分类频道后，同步README和完整状态报告。
